# Farm-Beware

Isometric 3D farming, cooking, and night-brawl combat game developed in **Unity 6000.3.20f1 (URP)**.

---

## 🚀 Quick Start
1. Open the repository in **Unity Hub** using **Unity 6000.3.20f1**.
2. Open the main staging scene: `Assets/Scenes/StagingScene.unity`.
3. Press **Play** (`Ctrl + P`) in the Editor to test current features.

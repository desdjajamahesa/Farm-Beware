# Preconditions

Conditions that must be met prior to testing.

- Have a dirty vegetables

# Test Data

Data used in the testing.

- Vegetables (item)

# Test Steps

The steps carried out by the tester.

1. After harvesting the crops
2. Open inventory and you will see a dirty vegetable
3. Close inventory interface
4. Go to kitchen sink
5. Open interface kitchen sink
6. Drag dirty vegetable form inventory to kitchen sink
7. Click ‘Wash’ to wash dirty vegetables
8. observe the vegetable in inventory

# Expected Result

The expected outcome if the feature operates in accordance with the specifications.

- The vegetable can wash in kitchen sink
- Can Open the kitchen interface
- Can drag item into sink
- get clean vegetables

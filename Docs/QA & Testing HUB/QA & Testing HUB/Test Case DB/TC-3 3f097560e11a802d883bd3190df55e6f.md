# TC-3

Test Case: Move the player using directional controls
Scenarios: Player Movement (../Test%20Scenarios%20DB/Player%20Movement%203dc97560e11a80319ec6eccb50305ab2.md)
Priority: Critical
Status: Active
Type: Smoke

# Preconditions

Conditions that must be met prior to testing.

- The player is alive and in an open area

# Test Data

Data used in the testing.

- Movement Player Data (W,A,S,D, Shift, Space)

# Test Steps

The steps carried out by the tester.

1. Enter Gameplay
2. Provide input for each supported direction (W, A, S, D, Shift, Space).
3. Observe the direction of movement.
4. Release the input.

# Expected Result

The expected outcome if the feature operates in accordance with the specifications.

- The player moves according to the input. Once the input is released, the movement stops in accordance with the specified control behaviour. The game remains responsive.

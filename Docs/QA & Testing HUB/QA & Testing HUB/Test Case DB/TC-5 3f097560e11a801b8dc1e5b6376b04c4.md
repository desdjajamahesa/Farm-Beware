# TC-5

Test Case: Selling one harvest & Buy Item
Scenarios: Verify player can complete a basic trade (../Test%20Scenarios%20DB/Verify%20player%20can%20complete%20a%20basic%20trade%203ee97560e11a8084b24bf3da3415ddf4.md)
Priority: Medium
Status: Draft
Type: Smoke

# Preconditions

Conditions that must be met prior to testing.

- Having vegetables to sell
- Having gold to buy something

# Test Data

Data used in the testing.

- Gold
- Item

# Test Steps

The steps carried out by the tester.

1. Enter gameplay.
2. Find and interact with a Merchant.
3. Verify the Merchant interface opens.
4. Select an item and purchase it.
5. Verify the purchased item is received and Gold decreases correctly.
6. Select a vegetable and sell it.
7. Verify the vegetable quantity decreases and Gold increases correctly.
8. Close the Merchant interface.

# Expected Result

The expected outcome if the feature operates in accordance with the specifications.

- Players can open the merchant interface
- Players can sell & buy items
- Players can close the merchant interface

# Notes

Additional notes regarding test cases.

- There is a bug when closing the merchant interface, whereby the cursor disappears. However, it reappears when opening the inventory or the pause menu.
